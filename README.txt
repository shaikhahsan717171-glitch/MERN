MERN STACK PRACTICALS - TXT FILES
==================================

This ZIP contains 42 separate text files for Practical 1a through Practical 8c.
Each sub-practical is saved independently, for example Practical_1a.txt and Practical_1b.txt.

The contents are extracted from the supplied "Edit Mern General.pdf". Procedures, commands,
JavaScript/React/Express/MongoDB code, instructions, and the source's textual output labels are
retained at full length; repeated PDF page headers/footers and page-break artifacts were removed
for readability. The text was not intentionally shortened. Each file now has an Aim line in the
format "Aim: Practical 1a - [specific task]", customized for that sub-practical.

A TXT file cannot embed screenshots that appear in the PDF, so screenshot-only output images are
not included. Any output descriptions/text present in the PDF extraction remain in the relevant file.

Source numbering note: the PDF contents page lists Array Methods as Practical 2d, but the body
heading is printed as "e)" and the following object-manipulation practical is also printed "e)".
The Array Methods file is named Practical_2d.txt to follow the contents page, and the source
heading is retained inside the file.
